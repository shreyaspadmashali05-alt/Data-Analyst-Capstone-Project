# 📊 IBM Data Analyst Capstone Project
## 📌 Project Overview

This project was completed as the capstone project of the IBM Data Analyst Professional Certificate. It demonstrates an end-to-end data analytics workflow, from data collection and preparation to exploratory analysis, visualization, dashboard development, and business recommendations.

The analysis focuses on identifying current technology trends, in-demand programming languages, databases, platforms, and developer demographics using survey data.

## 🛠️ Tools & Technologies

- Python
- SQL
- Excel
- Jupyter Notebook
- Google Looker Studio

### 🎯 Project Objectives

- Analyze survey data to identify current trends in technology usage and developer demographics.
- Identify the most in-demand programming languages, databases, platforms, and other technologies.
- Explore technology preferences and usage patterns across different developer groups.
- Transform the analysis into clear visualizations and an interactive dashboard.
- Present actionable insights and recommendations based on the findings.
